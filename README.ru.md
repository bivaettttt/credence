# Credence · Цифровое кредитование

[English](README.en.md)

Credence моделирует рассмотрение заявки вымышленной компании. Заявитель управляет организацией, документами и черновиками. Кредитный аналитик берёт заявку из очереди, проверяет комплект, рассчитывает учебную риск-оценку и даёт рекомендацию. Риск-офицер принимает мотивированное решение. Администратор ведёт версии продуктов, пользователей и аудит.

## Запуск

```sh
docker compose up --build
```

[Консоль](http://127.0.0.1:8110) · [Swagger UI](http://127.0.0.1:8110/api/docs)

Локальные логины `applicant`, `other`, `analyst`, `risk`, `admin` используют `Credence-demo-local`. [.env.example](.env.example) содержит порты и начальный пароль. Compose ждёт PostgreSQL, применяет Alembic и создаёт синтетические организации и продукты. Web публикуется на loopback.

## Модель процесса

Два типа обязательных документов и данные компании проверяются при подаче. Неизменяемый снимок фиксирует версию продукта и материалов. Проверка, оценка и рекомендация привязаны к подаче. Запрос информации убирает актуальность оценки, повторная подача формирует новый снимок. Одобрение риск-офицером и создание предложения происходят в одной транзакции. Учебный график использует целые копейки, базисные пункты и равные доли основного долга. У предложения есть семидневный срок.

Python, FastAPI, Pydantic, SQLAlchemy, Alembic и PostgreSQL формируют модульный монолит. React, TypeScript и Vite обслуживаются через nginx. API проверяет роль и членство, а также версию записи. Критические POST принимают `Idempotency-Key`. Токены в памяти браузера отзываются на выходе. Пароли хешируются Argon2id, история защищена триггерами PostgreSQL.

## Границы и развитие

Система работает с синтетическими данными и учебными решениями. Скоринг описывает сработавшие правила и требует ручной оценки. Документы представлены метаданными. Срок предложения материализуется при ответе или вызове команды истечения. Следующие шаги для развития — выделенные политики хранения, фоновое истечение предложений и независимая проверка более сложных правил. Публичная лицензия отдельно не заявлена.
